# neowayfar - a Wayfar 1444 recreation
There was once a game called Wayfar 1444, led by somebody called Hawgpadre. It was based on HellMOO's HellCore, which is ultimately a descendant of LambdaMOO.

This project aims to recreate it. While it originally was TCP, the beginning of the recreation was from an UDP text game, so it conserved that architecture.

The original_information directory contains archived tutorial-guides, as well as images displaying how things should look like: for example, NPCs, combat, space travel, biomes, creatures and so forth. They're the reference, slim as it may be.
